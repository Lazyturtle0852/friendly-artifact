# 指摘ログ(このスキルの根拠)

2026-08〜2026-09 の3案件(A: 時系列異常検知 API と最終報告書、B: 定点カメラ画像のセグメンテーション検証、C: 植物画像の生育分類レポート)で、成果物に対して実際に受けた指摘の要約と分類。固有名詞・案件固有の語は一般化している。
分類番号は SKILL.md の根本原因表に対応する。新しい指摘は末尾に同じ形式で追記する。

| 分類 | 根本原因 |
|---|---|
| 1 | 仕組みの説明を飛ばして結果を出した |
| 2 | 数値だけで現物を見せなかった |
| 3 | AIが勝手に決めた・省いたことに根拠がない |
| 4 | 結論が埋もれる・重要度順になっていない |
| 5 | 凡例・用語・文書間の整合が崩れている |
| 6 | 指標を信じて現物を見ていない・考察がない |
| P | プロセス(進め方)への指摘 |
